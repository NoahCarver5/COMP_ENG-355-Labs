# d8m *(reused from Lab 5)*

Camera interface for the Terasic D8M module. Outputs Bayer-decoded RGB888 pixels at 25 MHz.

## Ports (key signals)

| Port | Dir | Width | Description |
|------|-----|-------|-------------|
| `clk_25` | in | 1 | 25 MHz camera pixel clock |
| `d8m_*` | in/out | — | Physical camera I/O (MIPI, I2C config) |
| `pixel_valid` | out | 1 | RGB pixel is valid this cycle |
| `pixel_data` | out | 24 | RGB888 output pixel |
| `pixel_x` | out | 10 | Column (0–639) |
| `pixel_y` | out | 9 | Row (0–479) |

## Notes

- Reused directly from Lab 5; do not modify.
- Feeds into `video_store` write port.
- Camera clock (25 MHz) is generated by the PLL IP alongside the 100 MHz system clock.
